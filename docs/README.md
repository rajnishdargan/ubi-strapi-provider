# UBI Strapi Provider

Content management system for UBI benefits built with Strapi v5.

## Quick Start

1. Clone and install:
```bash
git clone <repository-url>
cd strapi
yarn install
```

2. Set up environment:
```bash
cp .env.example .env
```

3. Start with Docker:
```bash
docker-compose up -d
```

Admin panel: http://localhost:1337/admin
