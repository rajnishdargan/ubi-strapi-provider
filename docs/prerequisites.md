# Prerequisites

Required software and services for UBI Strapi Provider.

## Software Requirements

- Node.js 18.x
- Docker & Docker Compose v2.x
- Git

## Services

- PostgreSQL 14.17 (provided via Docker)
- Default ports:
  - PostgreSQL: 5432
  - PGAdmin: 8082 (optional)

## System Requirements

### Development
- 4GB RAM
- 10GB disk space
- Internet connection

### Production
- 8GB RAM
- 20GB disk space
- SSL certificate
