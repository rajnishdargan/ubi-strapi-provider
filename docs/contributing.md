# Contributing Guide

## Branches

- `main` - Production code
- `develop` - Integration branch
- `feature/*` - New features
- `fix/*` - Bug fixes
- `docs/*` - Documentation

## Development Flow

1. Branch from develop
2. Make changes
3. Test
4. Submit PR
5. Address reviews
6. Merge

## Standards

### Code
- Use TypeScript strict mode
- Follow ESLint rules
- Format with Prettier
- Write tests
- Document APIs

### Pull Requests
- Clear description
- Link issues
- Update docs
- Add tests
- Fix lint errors

### Security
- Validate inputs
- Check permissions
- Secure admin routes
- Follow JWT best practices

### Performance
- Optimize queries
- Use pagination
- Monitor response times
- Check query impact

## Support

For help:
- Check docs
- Review issues
- Include examples
- Attach logs
